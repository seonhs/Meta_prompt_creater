# metaprompt
프롬프트를 만들거나 개선하기 위한 프롬프트
# prompt
AI에게 무언가를 시키거나 물어볼 때 입력하는 지시문이나 질문
# 용도
- 프롬프트 생성: 작업 설명만 주면 잘 구조화된 프롬프트를 만들어 주는 템플릿
- 프롬프트 개선: 내가 쓴 프롬프트를 주고 모호한 부분이나 개선점을 찾게 하는 방식
- 프롬프트 평가: 만들어진 프롬프트가 목적에 맞는지 채점하거나 테스트 케이스를 만들게 하는 방식
# 각 프롬프트에 입력 정보 확인
## 티스토리_블로거_메타프롬프트
### 입력 정보
- 주제: [주제]
- 핵심 키워드: [키워드]
- 초안·메모: [초안·메모]
